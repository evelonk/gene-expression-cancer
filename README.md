# Gene Expression Cancer RNA-Seq — PCA, SVM, K-means

Классификация типа рака (BRCA, KIRC, COAD, LUAD, PRAD) на данных
[Gene Expression Cancer RNA-Seq](https://archive.ics.uci.edu/dataset/401/gene+expression+cancer+rna+seq)
(UCI ML Repository, часть TCGA Pan-Cancer)

## Результат

| Модель | Accuracy | Macro F1 | Время обучения |
|---|---|---|---|
| SVM без PCA, 5-fold CV | 0.9891 ± 0.0063 | 0.9902 ± 0.0060 | 1.916 сек/фолд |
| SVM с PCA, 5-fold CV | 0.9875 ± 0.0080 | 0.9888 ± 0.0071 | 0.042 сек/фолд |

5-fold кросс-валидация показала, что разница в точности статистически не значима (доверительные диапазоны
полностью перекрываются), надежно воспроизводимое преимущество
это скорость: ускорение примерно в **45 раз**

K-means — **Adjusted Rand Index = 0.8146**
при сравнении с реальными типами рака

## Задача и данные

801 образец, 20 531 признак, 5 классов:
BRCA, KIRC, COAD, LUAD, PRAD, признаков в 25 раз больше, чем объектов

## Пайплайн проекта

```
1. Загрузка данных
2. EDA
3. Препроцессинг — train/test split, масштабирование
4. PCA, сравнение с t-SNE
5. SVM с PCA и без
6. K-means — метод локтя/silhouette, ARI, таблица сопряженности, визуальное
   сравнение с реальными классами
7. Выводы
```

## EDA: ключевые находки

**Обоснование PCA**
801 объект против 20 531 признака означает, что почти любая модель без
снижения размерности рискует переобучиться

## PCA

**435 компонент из 20 531 объясняют 95% дисперсии**

**2D-визуализация первых двух компонент** показала, что KIRC отделяется от остальных типов почти идеально
уже на этом этапе

**t-SNE как проверка — и она опровергла первое впечатление от PCA.**
Нелинейная визуализация (t-SNE поверх PCA-компонент) развела все пять типов
рака на отдельные плотные кластеры

## SVM

1. Сравнение на одном train/test сплите показало SVM с PCA идеальной
   (100%/100%), без PCA — 98.14%/98.40%.
2. Проверка через `classification_report` и размер `support` показали, что результат мог быть переоценен из-за размера выборки
3. 5-fold кросс-валидация подтвердила подозрение: диапазоны accuracy/F1 для
   версий с PCA и без PCA полностью перекрываются
4. Единственное направление, где PCA дала стабильное, воспроизводимое
   преимущество это скорость обучения

## K-means

**ARI = 0.8146** — хорошее, но не идеальное совпадение с реальными типами
рака. Метод локтя и silhouette score **не дали однозначного, самостоятельного
подтверждения k=5** (silhouette пиковый на k=7); k=5 использовался осознанно
как известное число реальных классов, а не как объективно найденный
алгоритмом оптимум

**Таблица сопряженности выявила находку, отличную от предсказанной по PCA.**
KIRC (116 из 116) и PRAD (107 из 109) выделились почти идеально без единой
метки при обучении. Путаница оказалась не между PRAD и LUAD из-за того, что **LUAD не образовал
собственного кластера вообще** — 111 из 113 объектов растворились в общем
кластере вместе с частью BRCA и COAD, визуальное сравнение (реальные классы
vs найденные кластеры на PCA-плоскости) подтвердило то же самое.

## Что можно улучшить дальше

- Feature selection на основе биологической значимости генов вместо/вместе
  с PCA
- Иерархическая кластеризация вместо K-means — проверить, разделится ли
  смешанный кластер BRCA/COAD/LUAD на более чистые подгруппы при менее
  жестком предположении о форме кластеров
- Повторить ARI на нескольких `random_state` для K-means, чтобы убедиться,
  что 0.8146 — устойчивый результат
